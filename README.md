```

├── Program.cs              // только Main и вызовы
└── Tasks/
    ├── Loops.cs            // циклы for
    ├── Conditions.cs       // if / else if / else + циклы
    ├── Arrays.cs           // массивы
    └── ArraysMethods.cs    // методы с параметрами
```

Каждая задача это отдельный `public static` метод. В `Main` вызывается только нужный:

```csharp

static void Main(string[] args)
{
    Arrays.Task11();
}
```

## Разобранные ошибки

Ошибки полезнее всего записывать: так они перестают повторяться.

| Ошибка | Причина | Как исправить |
|---|---|---|
| `IndexOutOfRangeException` | индекс вышел за границы массива | цикл `i < arr.Length`, старт с `i = 0` |
| `OverflowException` при `new int[n]` | отрицательный размер массива | проверка `if (n <= 0)` до создания |
| «does not exist in the current context» | компилятор не нашёл имя: опечатка или нет `using` | проверить имя и `using` |
| «inaccessible due to its protection level» | метод найден, но закрыт | добавить `public` |
| Метод возвращает результат после первого элемента | `return sum;` стоит внутри цикла | вынести `return` на уровень после `for` |
| Проверка аргументов не работает на пустом массиве | проверка стоит внутри цикла, а он не выполняется | проверять аргументы до цикла, в начале метода |
| Диапазон из одного числа (`from == to`) даёт `0` | строгое `<` вместо `<=`, лишнее условие отрезает работу | убрать лишнюю проверку, тестировать граничные значения |
| Из метода с типом `int` нельзя вернуть текст | тип возврата задаётся один раз в сигнатуре | пока `-1` как признак ошибки; позже исключения (`throw`) |

## Заметки на будущее

- `i` это номер ящика, `arr[i]` это то, что лежит внутри.
- Максимум и минимум стартуют с первого элемента, а не с нуля.
- Для суммы старт `0`, для произведения старт `1`.
- Перед кодом пишу план одним-двумя строками комментарием. В плане только то, что делает сам метод, и в том порядке, в каком это идёт в коде.
- Методы называю глаголом (`FindMax`), классы существительным (`Arrays`). Имя метода должно говорить, что он делает.
- Не называю параметры ключевыми словами (`from`), лучше `min` / `max` или `lower` / `upper`.
- `return` внутри цикла завершает весь метод, это удобно для поиска первого совпадения.
- Проверка аргументов стоит в начале метода, до основной работы, и выполняется один раз.
- Условие, которое внутри цикла каждый раз даёт один и тот же ответ, выносится из цикла.
- `-1` как «не найдено» подходит для индекса, но неоднозначно, если `-1` может быть настоящим результатом (например, суммой).
- Метод, который считает, ничего не печатает: вывод делает вызывающий код.
- Тесты: обычный случай, граница, пустой массив, «ничего не найдено». Ожидаемый ответ записываю до запуска.
