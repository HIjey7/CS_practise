# Practise1 · C# с нуля

Учебный репозиторий: задачи на C#, решения и дневник прогресса.
Цель: подготовиться к чемпионату «Профессионалы» (разработка игры на C# + Unity, февраль).

## Структура проекта

```
Practise1/
├── Program.cs          // только Main и вызовы
└── Tasks/
    ├── Loops.cs        // циклы for
    ├── Conditions.cs   // if / else if / else + циклы
    ├── Arrays.cs       // массивы
    └── ArraysMethods.cs    // методы с параметрами
```

Каждая задача это отдельный `public static` метод. В `Main` вызывается только нужный:

```csharp
using Practise1.Tasks;

static void Main(string[] args)
{
    Arrays.Task11();
}
```

## Разобранные ошибки

Ошибки полезнее всего записывать: так они перестают повторяться.

| Ошибка | Причина | Как исправить |
|---|---|---|
| `IndexOutOfRangeException` | индекс вышел за границы массива | цикл `i < arr.Length`, старт с `i = 0` |
| `OverflowException` при `new int[n]` | отрицательный размер массива | проверка `if (n <= 0)` до создания |
| «does not exist in the current context» | компилятор не нашёл имя: опечатка или нет `using` | проверить имя и `using` |
| «inaccessible due to its protection level» | метод найден, но закрыт | добавить `public` |

## Заметки на будущее

- `i` это номер ящика, `arr[i]` это то, что лежит внутри.
- Максимум и минимум стартуют с первого элемента, а не с нуля.
- Для суммы старт `0`, для произведения старт `1`.
- Перед кодом пишу план одним-двумя строками комментарием.
- Методы называю глаголом (`FindMax`), классы существительным (`Arrays`).
